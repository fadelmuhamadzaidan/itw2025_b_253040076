# 🌐 Personal Portfolio Website

Website ini merupakan **portfolio pribadi** milik **Fadel Muhamad Zaidan** yang dibuat untuk menampilkan profil, skill, pendidikan, hobi, serta informasi kontak dalam satu halaman website yang modern, responsif, dan mudah digunakan.

---

## 👤 Tentang Website

Portfolio ini dirancang sebagai **single page website** dengan navigasi yang mengarah ke setiap section. Website ini cocok digunakan sebagai:

- Portfolio mahasiswa
- Personal branding
- Media perkenalan diri di dunia IT

---

## 🚀 Fitur Utama

### 1. Responsive Design

Website sudah responsif dan dapat diakses dengan baik di:

- Desktop
- Tablet
- Smartphone

Menggunakan file terpisah:

- `style.css` → styling utama
- `responsive.css` → penyesuaian layar kecil

---

### 2. Navigation & Burger Menu

- Navigasi menggunakan anchor link (`#home`, `#services`, dll)
- Burger menu otomatis muncul di layar kecil

---

### 3. Hero Section

Menampilkan:

- Nama lengkap
- Deskripsi singkat diri
- Foto profil

Sebagai tampilan pertama yang personal dan profesional.

---

### 4. Services Section

Berisi layanan/keahlian utama:

- UI/UX Design
- Application Development
- Web Development

Menggunakan **SVG icon** agar ringan dan tajam.

---

### 5. Portfolio / Hobby Section

Menampilkan hobi dalam bentuk card yang berisi:

- Gambar
- Judul
- Tag teknologi
- Deskripsi singkat

Struktur ini mudah dikembangkan untuk project asli di masa depan.

---

### 6. Fun Fact Section

Berisi fakta unik tentang diri sendiri dengan ikon dari **Boxicons**, membuat website terasa lebih santai dan tidak kaku.

---

### 7. Skills & Education

- **Education** ditampilkan dalam bentuk timeline
- **Skills** dibagi dalam dua kolom untuk kemudahan membaca

Fokus pada skill dasar web development dan frontend.

---

### 8. Contact Form

- Menggunakan **Formspree**
- Tidak memerlukan backend
- Pesan langsung dikirim ke email

---

### 9. Footer & Social Media

- Icon media sosial menggunakan SVG
- Mendukung personal branding

---

## 🛠️ Teknologi yang Digunakan
